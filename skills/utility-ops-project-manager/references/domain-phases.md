## 1. Video Game (Solo/Indie)

| Universal Phase | Game Dev Equivalent | Key Deliverable |
|---|---|---|
| 0: Concept | Ideation | One-paragraph concept + core loop statement |
| 1: Prototype | Prototype(s) | Playable proof of core mechanic — fast, disposable, no final art |
| 2: Vertical Slice | Vertical Slice | One polished segment (~15–30 min of gameplay) at ship quality |
| 3: Pre-Production | Pre-Production | GDD, full WBS, milestone calendar, feature lock date |
| 4: Production (Features) | Alpha | All systems, mechanics, and UI in place — Feature Complete |
| 5: Production (Content) | Beta | All levels, content, story — Content Complete |
| 6: Polish & Wrap | Gold / Release Candidate | Bug-fixed, optimized, platform-certified build |
| 7: Release & Close | Ship + Post-Mortem | Released build + documented learnings |

**Critical distinction (Ismail, 2022):**
- Prototype answers: "Should I make this game?"
- Vertical Slice answers: "Can I make this game?"
Confusing these two is the most common and costly planning error in indie game development.

**Velocity unit:** hours per level / per screen / per mechanic system

**Feature lock rule:** Once Alpha is reached, the feature set is frozen.
No new mechanics, systems, or UI enter the game. Scope proposals go to the next project.

**WBS Level 2 deliverables (typical):**
- Core mechanics / systems
- Level/content set
- UI screens
- Audio (music tracks + SFX)
- Art assets (characters, environments, UI art)
- QA / bug pass
- Release packaging (store page, screenshots, trailer)

## 2. Novel / Long-Form Fiction

| Universal Phase | Novel Equivalent | Key Deliverable |
|---|---|---|
| 0: Concept | Premise | One-sentence premise + protagonist + central conflict |
| 1: Prototype | Outline / Beat Sheet | Full plot outline — beginning, middle, end, major beats |
| 2: Vertical Slice | Pilot Chapter | One complete chapter written to final quality |
| 3: Pre-Production | Story Bible + Schedule | Character sheets, world-building notes, chapter list, calendar |
| 4: Production (Features) | First Draft | All chapters drafted — structure locked |
| 5: Production (Content) | Structural Revision | Plot holes fixed, arcs complete, nothing missing |
| 6: Polish & Wrap | Line Edit + Proof | Clean manuscript ready for publication |
| 7: Release & Close | Publication + Post-Mortem | Published + documented learnings |

**Pilot chapter purpose:** One chapter written to final quality (not a rough draft)
reveals your actual words-per-session rate, your revision ratio, and your quality ceiling.
This is the velocity calibration event. Do not skip it.

**Velocity units:** words per session / chapters per month

**Feature lock equivalent:** After First Draft is complete, no new major plot threads,
characters, or structural elements are introduced. Structural Revision fixes what exists;
it does not expand scope.

**WBS Level 2 deliverables (typical):**
- Outline / beat sheet
- Character sheets and world-building docs
- First draft (broken into chapters)
- Structural revision pass
- Line edit pass
- Copy edit / proofread pass
- Cover design and formatting (if self-publishing)
- Publication / submission

**MoSCoW application:**
- Must: Core plot, protagonist arc, primary conflict resolution
- Should: Secondary character arcs, subplot threads
- Could: Worldbuilding depth, additional POV chapters, appendices
- Won't (this book): Companion volumes, spin-offs, extended lore

## 3. Comic Book / Graphic Novel / Webtoon

| Universal Phase | Comics Equivalent | Key Deliverable |
|---|---|---|
| 0: Concept | Pitch Concept | Logline + visual style reference + tone |
| 1: Prototype | Script + Rough Thumbnails | 3–5 pages scripted and thumbnailed |
| 2: Vertical Slice | 2–3 Finished Pages | Complete pipeline test: script → pencil → ink → color → letter |
| 3: Pre-Production | Production Plan | Full script outline, page count, pipeline schedule |
| 4: Production (Features) | Script Complete | All pages scripted — story structure locked |
| 5: Production (Content) | Art Production | All pages through final art pipeline |
| 6: Polish & Wrap | Final Review + Format | Lettering review, format for print/digital, cover complete |
| 7: Release & Close | Publication + Post-Mortem | Published + documented learnings |

**Vertical Slice purpose (comics):** 2–3 pages taken through the full production
pipeline (script → pencil → ink → color → letter) at target quality establishes:
- Actual time per page at each stage
- Which stages are bottlenecks
- Whether the visual style is achievable at scale
Do not begin full production without this calibration.

**Velocity units:** pages per week / pages per stage per week

**Feature lock equivalent:** After all pages are scripted, no new pages, characters,
or plot beats are added. Art production fills what the script defines; it does not expand it.

**Pipeline stages and velocity tracking (track separately):**
- Scripting (pages/week)
- Thumbnailing / layouts (pages/week)
- Penciling (pages/week)
- Inking (pages/week)
- Coloring (pages/week)
- Lettering (pages/week)

Each stage has its own velocity. The bottleneck stage controls the release schedule.

**WBS Level 2 deliverables (typical):**
- Story outline
- Full script
- Thumbnails / layouts (all pages)
- Pencils (all pages)
- Inks (all pages)
- Colors (all pages)
- Lettering (all pages)
- Cover + promotional assets
- Publication format (print / digital / webtoon upload)

## 4. Short Fiction / Novelette / Novella

Same model as Novel but compressed. Phases 1 and 2 merge:
- Prototype = outline + one scene draft
- Vertical Slice = skip (at short-form scale, the outline IS the vertical slice)

Velocity units: words per session

Typical WBS collapses to:
- Outline
- First draft
- Revision pass
- Final edit
- Publication / submission

## 5. Tabletop Game (TTRPG or Board Game)

| Universal Phase | Tabletop Equivalent | Key Deliverable |
|---|---|---|
| 0: Concept | Game Concept | Core mechanic statement + player count + play time |
| 1: Prototype | Paper Prototype | Handmade, playable version — no production values |
| 2: Vertical Slice | Playtest Build | Cleaned-up version tested with real players (not you) |
| 3: Pre-Production | Component Plan | Full component list, rule book outline, production calendar |
| 4: Production (Features) | Rules Complete | All mechanics finalized, rule book complete |
| 5: Production (Content) | Components Complete | All cards, boards, tokens, art complete |
| 6: Polish & Wrap | Print-Ready Files | Print-and-play or print-ready files delivered |
| 7: Release & Close | Release + Post-Mortem | Published (itch.io, Kickstarter, DTRPG, etc.) + learnings |

**Velocity units:** components per week / pages of rules per week
