# Linear Vocabulary Mapping

Maps Linear's terminology to the skill's terminology. Load when working in Linear.

## Workspace Setup

- Workspace: **Managed Projects**
- Team: **Creative Work** (identifier: `CW`)
- One Linear project per creative project (e.g., The Loop, [comic name], [novel name])

## Term Mapping

| Linear term | Skill term | Notes |
|---|---|---|
| Project | Project | One per creative project |
| Issue | Task / work package | The atomic unit of work |
| Cycle | Sprint | 1–2 week time box |
| Backlog (status) | Project backlog | All work not yet in a cycle |
| Priority: Urgent | MoSCoW: Must | Non-negotiable for this phase |
| Priority: High | MoSCoW: Should | High value, include if possible |
| Priority: Medium | MoSCoW: Could | Nice to have |
| Priority: No priority | Parking lot | Ideas, future candidates |
| Status: Todo | Not started | In scope, not yet begun |
| Status: In Progress | Active / current sprint | Being worked now |
| Status: Done | Complete | Exit gate passed |
| Status: Cancelled | Won't (this project) | Explicitly out of scope |
| Label: quick-decision | ≤5 min task | Tiny decision or answer |
| Label: quick-win | ≤15 min task | Short focused burst |
| Label: quick-task | ≤30 min task | One solid chunk |
